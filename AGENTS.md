# EcoScan AI

## Project Overview

EcoScan AI is an AI-powered waste classification web application built for the IndonesiaNEXT Hackathon.

The application helps users identify waste correctly and provides environmental education using AI.

The project focuses on delivering a complete production-ready MVP within 24 hours.

---

## Tech Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- Supabase
- OpenAI Responses API

---

## MVP Features

- Authentication
- Waste Scan
- AI Analysis
- Scan History
- Dashboard
- Eco Score
